# Task Manager

A simple task management web app built with HTML, CSS, and Vanilla JavaScript.

🔗 **[Live Demo](https://lumine404.github.io/Task-Manager/)**

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Tasks persist after refreshing the page

## Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage

## What I Learned

- DOM manipulation
- Event listeners and event handling
- Working with arrays and objects
- Dynamically creating HTML elements
- Persisting data with Local Storage
